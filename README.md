# QR Code Generator

A sleek, modern, and lightweight web application that allows users to instantly generate QR codes from URLs or any text input.

## 🚀 Features

- **Instant Generation:** Create QR codes in real-time with a single click or by pressing Enter.
- **Easy Download:** Save your generated QR codes as high-quality PNG images with the new download button.
- **Modern UI:** Clean, responsive design built with CSS variables and a focus on user experience.
- **High Quality:** Uses `qrcode.js` for reliable, high-resolution QR code generation with high error correction levels.
- **Mobile Friendly:** Fully responsive layout that works perfectly on desktops, tablets, and smartphones.
- **Zero Dependencies:** Runs entirely in the browser using a lightweight CDN-hosted library.

## 🛠️ Built With

- **HTML5:** Semantic structure for accessibility.
- **CSS3:** Modern styling with Flexbox, CSS Variables, and custom transitions.
- **JavaScript (Vanilla):** Light logic for handling inputs and triggering generation.
- **[qrcode.js](https://davidshimjs.github.io/qrcodejs/):** A cross-browser QR code library.

## 📦 How to Use

1.  Clone the repository or download the `index.html` file.
2.  Open `index.html` in any modern web browser.
3.  Enter your URL or text in the input field.
4.  Click **"Generate QR Code"** or press **Enter**.
5.  Your QR code will appear instantly!
